# DDID prioritized review outputs

Generated from the user-supplied `Interaction Information.csv` export.

- `ddid_prioritized_review_queue.csv`: exact normalized matches for the 17 target medicine names, with original DDID fields retained and reviewer columns appended.
- `ddid_prioritized_review_summary.json`: row counts and triage band counts.

Triage is administrative only. `A_review_first` means a food-type record with a human experimental context and PMID or DOI field; it is not proof of clinical relevance or a recommendation to warn a patient. Confirm source paper, exposure/form, design, result, population, dose, and current authoritative guidance before approving any message.
